# Editorial Style Guide

## Voice

Original, objective, direct, testing-first, comparison-driven, Canadian-buyer-focused, skimmable, trustworthy, non-salesy. Technical but understandable. Short paragraphs.

## Every review and guide should

- Answer the search intent quickly (first paragraph).
- Explain how the recommendation was chosen.
- Reference the relevant test categories.
- Include Canadian pricing and availability where relevant.
- Offer alternatives.
- State who should buy and who should skip.
- Avoid exaggerated claims, filler, and copied wording.

## Preferred phrasing

- "This laptop is a strong choice if…"
- "It performs well for…"
- "The main drawback is…"
- "Most buyers should consider…"
- "This model makes the most sense when discounted below…"
- "If you need better battery life, consider…"

## Avoid

- "Game changer", "ultimate powerhouse", "unleash your productivity"
- "Perfect for everyone", "best laptop ever", "you won't believe"

## Templates (mirrored in code)

- **Best list** — intro (direct answer + criteria) → summary table → ranked picks (Best Overall / Mid-Range / Budget / Premium / Alternative / Also Great) → Notable Mentions → How We Picked → How We Test → How to Choose → FAQ → Related.
- **Review** — Quick Verdict → Pros/Cons → Score Breakdown → Use-Case Scores → Design → Display → Keyboard → Ports → Performance → Battery → Thermals → Software → Pricing → Compared To → Final Verdict → FAQ → Related → Discussion.
- **Comparison** — Quick Verdict → Winner by Use Case → Specs & Scores → Which Should You Buy? → FAQ → Related.

## Recommendation fields (per pick)

Image, name, score, best use case, tested configuration, Canadian price range, retailer availability, short verdict, what it does well, what it does poorly, who should buy, who should skip, compare button, review button.
